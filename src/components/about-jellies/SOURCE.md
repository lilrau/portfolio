# Jellyfish source

Adapted from the procedural ASCII ocean renderer in `kurage-dashboard/index.html`, supplied by the user in `kurage-dashboard-1.0.0.zip` (HorizonX, version 1.0.0, October 2026).

This integration keeps the bell, pulsing propulsion, tentacle simulation and glyph sampling. It removes the dashboard UI, particle snow, response modes and storage. The palette, density, transparency and lifecycle are adapted for the portfolio's About section. The original template is not included.

A gentle current balances the upward propulsion and keeps the jellyfish drifting near their distributed positions, so the section remains populated during longer visits.

The supplied README states that the template may be adapted for personal, client and commercial projects under the user's HorizonX license, and prohibits redistribution of its original source files.
